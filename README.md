# 🌐 Azure Landing Zone with Terraform

🔗 **Repository:** https://github.com/aniket-devop/azure-landing-zone-terraform

A production-inspired Azure Landing Zone built using Terraform following Microsoft's Cloud Adoption Framework principles. The infrastructure uses a **Hub-and-Spoke** architecture with reusable Terraform modules, secure networking, and centralized management.

> **Architecture Diagram**
>
> *(Keep your existing Mermaid diagram here.)*

### Highlights

* Hub-and-Spoke Virtual Network Architecture
* Azure Firewall & Azure Bastion
* Network Security Groups with least-privilege rules
* User Defined Routes (UDRs)
* Private DNS Zones
* Azure Key Vault with Private Endpoint
* Resource Group level RBAC
* Remote Terraform State in Azure Storage
* Reusable Parent-Child Terraform Modules
* Multi-environment deployment using tfvars
* GitHub Actions pipeline for `fmt`, `validate` and `plan`

### Technologies

`Azure` • `Terraform` • `GitHub Actions` • `Azure Key Vault` • `Azure Firewall`
