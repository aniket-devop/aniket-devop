## Featured Projects

### 1. AWS Landing Zone — Multi-AZ VPC, ALB, and EC2 with Terraform

`Terraform` `AWS` `GitHub Actions` `Docker`

A modular, production-style AWS landing zone built with Terraform: a 2-AZ VPC with public/private subnet segmentation, NAT Gateway egress, an internet-facing Application Load Balancer, EC2 instances in private subnets with least-privilege IAM (no SSH keys, access via SSM Session Manager), remote state in S3 with DynamoDB locking, and a GitHub Actions CI pipeline that runs `fmt`, `validate`, and `plan` on every pull request using OIDC authentication.

[View Repository](https://github.com/aniket-devop/aws-terraform-landing-zone-project)

---

### 2. Azure Landing Zone — Hub-and-Spoke with Terraform

`Terraform` `Azure` `GitHub Actions`

A hub-and-spoke Azure landing zone in Terraform: hub VNet with Azure Firewall and Bastion, a spoke VNet with an NSG-bounded subnet for AKS, RBAC-authorized Key Vault, and role assignments scoped to the resource group. CI pipeline runs `fmt`, `init`, and `validate` on every PR and push to main.

[View Repository](https://github.com/aniket-devop/azure-landing-zone-terraform)

---

### 3. Banking Fraud Detection System

`Docker` `React` `Node.js` `Python` `MongoDB` `AWS EC2` `GitHub Actions`

A full-stack banking fraud detection platform with a React frontend, Node.js/Python backend, MongoDB database, Docker containerization, and AWS EC2 deployment. Includes a GitHub Actions CI pipeline for automated builds and deployment.

[View Repository](https://github.com/aniket-devop/banking-fraud-detection-system)

---

### 4. GitHub Actions: Zero to Hero

`GitHub Actions` `Docker` `AWS EC2` `Python`

A CI/CD pipeline automation project demonstrating the full lifecycle of application delivery using GitHub Actions: code integration, testing and lint checks, DevSecOps security scanning, Docker image build, push to Docker Hub, and deployment to an AWS EC2 server.

[View Repository](https://github.com/aniket-devop/github-action-zero-to-hero)
